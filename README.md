# DaiChungCapital — Institutional M&A & Strategic Capital Platform

Nền tảng Tư vấn, Cấu trúc Giao dịch & Triển khai Sản phẩm M&A Định chế đa ngôn ngữ (**Tiếng Việt · English · 简体中文**), hỗ trợ tự động đồng bộ **Dark Mode / Light Mode** theo hệ điều hành và trình duyệt.

## Tính năng cốt lõi

- **Đa ngôn ngữ tức thời (`VI` / `EN` / `ZH`)**: Chuyển đổi toàn bộ giao diện, danh mục thương vụ, hồ sơ Blind Teaser, mục lục Phòng dữ liệu ảo (VDR) và tệp tải về sang Tiếng Việt, Tiếng Anh và Tiếng Trung.
- **Giao diện Sáng / Tối thông minh (`System` · `Light` · `Dark`)**: Tự động nhận diện và cập nhật trực tiếp theo cài đặt Sáng/Tối của máy tính/trình duyệt hoặc tùy chỉnh thủ công.
- **Trung tâm Triển khai Sản phẩm M&A (Deal Pipeline)**:
  - Bộ lọc đa chiều theo lĩnh vực, cấu trúc giao dịch, giai đoạn thẩm định, tìm kiếm từ khóa và chuyển đổi chế độ xem Lưới / Bảng dữ liệu.
  - Cửa sổ **Blind Teaser & VDR 3 ngăn**: Tóm tắt đầu tư, danh mục pháp lý xác thực, mục lục tài liệu VDR, luồng ký NDA điện tử cấp mã tham chiếu và tải hồ sơ tóm tắt.
  - Công cụ **Triển khai Sản phẩm M&A mới** trực tiếp trên giao diện.
- **Quy trình M&A 5 Bước Chuẩn hóa, Hệ sinh thái 3 Chủ thể & Dấu ấn Thương vụ Xuyên biên giới**.

## Khởi chạy dự án

```bash
# Cài đặt thư viện
npm install

# Chạy môi trường phát triển (http://127.0.0.1:5173)
npm run dev

# Đóng gói bản Production (thư mục dist/)
npm run build
```
